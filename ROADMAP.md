# Roadmap

## 0.2 · Fundamento utilizable

Pipeline multiformato, lineage, calidad, JSONL/TXT/Parquet/SQLite, UI localhost, ejecutable Windows, APK Android mínima, Pages y release reproducible.

## 0.3 · Actualización y extracción avanzada

- registro incremental y diffs de dataset;
- OCR con detección de escaneados y confianza;
- mejor preservación de layout, tablas y encabezados;
- chunking semántico de código y Markdown;
- budgets de red, robots, cache y commit pinning.

## 0.4 · Preparación específica

- adaptadores de salida para pretraining, conversaciones SFT, RAG y evals;
- split por fuente, detección de contaminación y sampling estratificado;
- validación declarativa de esquemas y data cards.

## Horizonte de producción

Workers aislados, colas, object storage, catálogo versionado, observabilidad, RBAC, DLP, políticas de retención y firma de artefactos. Cada ítem pasa a “operativo” solo con implementación, pruebas, documentación y evidencia CI.
