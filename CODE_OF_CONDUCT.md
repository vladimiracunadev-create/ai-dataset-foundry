# Código de conducta

Este proyecto busca una colaboración técnica respetuosa, inclusiva y basada en evidencia.

## Conducta esperada

- debatir ideas y cambios, no atacar personas;
- explicar supuestos y aceptar correcciones con evidencia;
- respetar privacidad, propiedad intelectual y divulgación coordinada;
- no publicar datos personales, financieros, secretos ni material discriminatorio;
- ayudar a que personas con distinta experiencia puedan participar.

## Conducta inaceptable

Acoso, discriminación, amenazas, doxxing, contenido sexual no solicitado, sabotaje deliberado, uso de datos de pago reales o explotación de terceros bajo pretexto de investigación.

## Aplicación

Reporta incidentes al mantenedor por un canal privado de GitHub. El mantenedor puede editar o retirar contenido, cerrar conversaciones o restringir participación. Se protegerá la confidencialidad en la medida razonable.

Este código adapta los principios del [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
